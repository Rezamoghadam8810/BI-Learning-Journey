BI Learning Journey
مسیر یادگیری هوش تجاری
English
This repository contains my hands‑on practice and learning projects in the Business Intelligence (BI) and Data Engineering domain.

The goal of this repository is to document my learning journey while working with different BI tools and data technologies. Each section contains exercises, small projects, and practical implementations based on real datasets such as AdventureWorks.

Repository Structure
The repository is organized by technology. Each folder contains exercises related to that specific tool.

Example structure:

ssis/ → SSIS exercises and ETL practice
sql/ → SQL practice and database scripts
powerbi/ → Power BI reports and data visualization projects
Inside each folder, exercises are organized in separate directories.

Each exercise includes:

The project files
SQL scripts if needed
Screenshots of the implementation
A dedicated README explaining the scenario and logic
Example
text
ssis/
   exercise-01-...
   exercise-02-AdventureWorks-ConditionalSplit
   exercise-03-...
Each exercise folder contains its own documentation and outputs.

Technologies Used
SQL Server
SSIS (SQL Server Integration Services)
Visual Studio 2019
AdventureWorks Sample Database
Power BI (in later sections)
Purpose
This repository serves as:

A personal learning archive
A structured practice environment
A portfolio demonstrating practical BI and ETL skills
