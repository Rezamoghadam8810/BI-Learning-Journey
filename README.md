\# BI Learning Journey

\### مسیر یادگیری هوش تجاری



\---



\## English



This repository contains my hands‑on practice and learning projects in the fields of \*\*Business Intelligence (BI)\*\* and \*\*Data Engineering\*\*.



The purpose of this repository is to document my learning process while working with different BI tools and data technologies. Most exercises use real or sample datasets such as \*\*AdventureWorks\*\*.



\---



\### Repository Structure



The repository is organized by technology. Each folder contains exercises related to a specific tool.



Example structure:



ssis/

sql/

powerbi/



📁 ssis/ → SSIS exercises and ETL practice  

📁 sql/ → SQL queries and database scripts  

📁 powerbi/ → Power BI reports and data visualization projects  



Inside each folder, exercises are organized in separate directories.



Example:



ssis/

&#x20;  exercise-01

&#x20;  exercise-02-AdventureWorks-ConditionalSplit

&#x20;  exercise-03



Each exercise folder includes:



\- 📦 Project files  

\- 🧾 SQL scripts (if required)  

\- 🖼️ Implementation screenshots  

\- 📄 A dedicated README explaining the scenario and solution logic
