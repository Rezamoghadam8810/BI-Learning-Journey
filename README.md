# SSIS XML Freight Analysis

This exercise reads data from an XML file, extracts the year from the date column, calculates the average freight per country, sorts the results, and exports the output.

## Steps Performed
1. **XML Source** – Load input file  
2. **Derived Column** – Extract Year  
3. **Aggregate** – Calculate Average Freight by Country  
4. **Sort** – Sort by country and/or year  
5. **Destination** – Export final output (image shown below)
